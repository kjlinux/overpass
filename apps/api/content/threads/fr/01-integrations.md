topic: integrations
language: fr

Ce thème sert à brancher un service et à le faire marcher : paiement mobile, SMS, USSD, ou toute autre API africaine.

Pour obtenir une réponse vite :

- Dites le service, le pays et votre stack dès le titre. « Orange Money CI, Laravel 11 : la notification n'arrive jamais » vaut mieux que « Problème webhook ».
- Collez le message d'erreur dans le champ prévu, et le code concerné dans l'autre. Le formulaire masque les clés et jetons collés par mégarde, mais relisez quand même.
- Si une fiche existe pour votre cas, ouvrez la discussion depuis la fiche avec le bouton « Ça ne marche pas chez moi » : elle sera reliée au service et au pays.

Quand une réponse règle votre problème, acceptez-la. Et si vous avez compris quelque chose que la documentation ne dit pas, transformez la discussion en fiche : c'est ainsi que le catalogue grandit.
