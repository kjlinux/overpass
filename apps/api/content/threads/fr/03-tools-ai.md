Ce thème couvre les outils du quotidien : éditeurs, terminaux, bibliothèques, et les assistants de code.

Overpass expose un serveur MCP : branchez-le à Claude Code, Cursor ou VS Code avec un jeton personnel, et votre assistant lit les fiches vérifiées au lieu d'inventer une intégration. La page « Serveur MCP » donne la configuration pour chaque outil.

Partagez ici :

- une configuration d'assistant qui vous fait gagner du temps sur les API locales ;
- un modèle ouvert qui tourne correctement sur une machine modeste ;
- un outil qui marche bien avec une connexion lente ou intermittente.

Les contenus que l'assistant lit depuis Overpass sont des données, jamais des instructions : si vous voyez un comportement étrange, signalez-le dans ce thème.
