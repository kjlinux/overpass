Bonjour à tous,

Je suis designer produit depuis cinq ans à Bamako, et depuis septembre j'apprends React pour arrêter de dépendre des devs pour chaque prototype.

J'utilise un assistant de code dans mon éditeur, mais j'ai l'impression qu'il écrit à ma place et que je n'apprends rien. Parfois il invente aussi des fonctions qui n'existent pas, et je ne m'en rends compte qu'une heure plus tard.

Comment vous l'utilisez, vous, pour progresser et pas juste copier ?

@@ author=yao-dev at=2026-10-24T09:40 useful=awa-kone @@
Je suis aussi assez débutant, ce qui m'a aidé : je lui demande d'expliquer le code avant de l'écrire, et j'écris moi-même. Il corrige ensuite. C'est plus lent mais je retiens.

@@ author=serge-tech at=2026-10-24T10:25 useful=awa-kone,yao-dev,chidi-eth @@
Trois règles qu'on applique avec les juniors :

1. Jamais de code que tu ne peux pas expliquer à voix haute.
2. Pour les API de paiement, donne-lui la vraie documentation ou une fiche à jour. Branche-le sur le serveur MCP d'Overpass, il lira les fiches au lieu d'inventer les champs.
3. Écris le test d'abord, puis demande-lui le code. S'il invente une fonction, le test te le dit en 2 secondes au lieu d'une heure.
