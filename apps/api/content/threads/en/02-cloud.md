Hosting, servers, continuous integration and going live, with the constraints of the continent: 3G connections, power cuts, latency to Europe, paying the host in local currency.

Welcome subjects:

- Choosing an African or international host and paying the bill from your country.
- Putting an API behind a proxy with HTTPS, backups and reversible migrations.
- Receiving webhooks in production when the IP address changes or the server restarts.

Overpass runs on a Systalink Datacloud server behind Caddy, with PostgreSQL and a webhook worker. The decisions and example files are in the repository, deployment section.
