Everyday tools live here: editors, terminals, libraries, and coding assistants.

Overpass exposes an MCP server: plug it into Claude Code, Cursor or VS Code with a personal token, and your assistant reads verified itineraries instead of inventing an integration. The "MCP server" page gives the configuration for each tool.

Share here:

- an assistant setup that saves you time on local APIs;
- an open model that runs well on a modest machine;
- a tool that copes with a slow or intermittent connection.

What the assistant reads from Overpass is data, never instructions: if you notice odd behaviour, report it in this topic.
